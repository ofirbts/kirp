KIRP Enterprise UI/UX Design Specification
Inspired by: view-page-source.com (dark-mode dashboard tool)
Product Context: Intelligence OS for enterprises – multi-tenant dashboards for events, agents, RAG search, governance, automation (n8n/Celery), observability, tenants/users. Dense operational data, audit trails, charts/tables. Target: Technical admins, operators, decision-makers.

1. Overall Vibe & Style
Theme: Dark-mode by default (professional, reduces eye strain for long sessions). Optional light-mode toggle.

Tone: Enterprise-grade tool – precise, trustworthy, dense info without clutter. Modern SaaS (Tailwind/Next.js aesthetic).

Key Principles:

Ample spacing, rounded corners (8-12px), subtle shadows.

Icons: Simple line icons or emojis (🔍 for search, ⚙️ for settings, 📊 for metrics).

Animations: Subtle (fade-in, scale on hover, loading spinners).

Responsive: Desktop-first (multi-panel), mobile stacks vertically.

2. Typography
Headings: Sans-serif modern (Inter, Plus Jakarta Sans) – bold for hierarchy.

H1: 48-56px, split lines with accent word (e.g., "KIRP" gradient).

H2: 32px, section headers.

H3: 24px, cards/tables.

Body: 14-16px, high readability.

Code/Monospace: JetBrains Mono for event IDs, JSON, logs (syntax highlighting: Prism.js style).

Line Height: 1.5-1.7 everywhere.

3. Color Palette
Category	Dark Mode	Light Mode	Usage
Background	#0f0f23 (dark navy)	#f8fafc	Main/app shell
Surface/Cards	#1a1b2e	#ffffff	Sections, modals
Text Primary	#f1f5f9	#0f0f23	Headings/body
Text Secondary	#94a3b8	#64748b	Labels, subtitles
Accent Primary	#06b6d4 (cyan/teal)	#0ea5e9	CTAs, links, highlights
Success	#10b981	#059669	Approvals, healthy metrics
Warning	#f59e0b	#d97706	Pending, risks
Error	#ef4444	#dc2626	Failures, alerts
Border	#334155	#e2e8f0	Dividers, inputs
Gradients: Cyan-to-blue for hero accents (e.g., background: linear-gradient(135deg, #06b6d4, #0ea5e9)).

4. Core Layout Structure
Fixed top nav + sidebar (collapsible on mobile) + main content with multi-panel grids.

text
[Header: Logo | Nav: Agents/Events/Governance/Tenants | Tenant Switcher | Theme Toggle | User Menu]

[Sidebar (20% width): Quick nav, Recent events, Metrics overview]

[Main Content (80%)]
├── Hero/Search Bar (Events/RAG query input)
├── Dashboard Grid (Cards: Live Events, Agent Runs, Governance Decisions)
├── Collapsible Sections (e.g., "Smart Analysis": SEO→Events, Agents→Pipelines)
├── Features Grid (8-12 cards)
├── Data Tables (Events log, Audit trail)
└── Footer (Links, Version)
Key Pages & Views
Dashboard Home: Hero input for event query/RAG search + stats cards (events/hour, agent runs, uptime).

Agents: List/table + inspector drawer (prompts, runs, traces).

Events: Timeline/table with filters (tenant/space), syntax-highlighted payloads.

Governance: Approval flows, policy simulator, audit logs (collapsible accordions).

Tenants/Users: Admin tables, RBAC matrix, demo data toggle.

Observability: Metrics charts (Prometheus-style), logs viewer.

5. UI Components & Patterns
Cards: Rounded (12px), subtle shadow, hover lift. Header (icon + title + badges) + body (table/list/chart).

Tables: Zebra-striped rows, sortable headers, row selection, expandable rows (for event details).

Badges/Pills: Status (e.g., "Active", "Pending Approval") – colored backgrounds, rounded.

Inputs/Forms:

Search bar: Prefix icon (🔍), autocomplete, debounce.

Multi-select: Tenant/space filters, tags.

Checkboxes: Custom styled (no native look).

Buttons:

Type	Style	Example
Primary	Filled accent bg, white text, icon-right	"Run Agent", "Approve"
Secondary	Outline border, accent text	"Edit", "Cancel"
Danger	Red fill	"Reject", "Delete"
Ghost	Transparent, hover bg	Sidebar nav
Modals/Drawers: Overlay from right (inspector), backdrop blur.

Charts: Radial speedometers (page load→pipeline latency), line charts (events over time), use Recharts.

Code Blocks: Editor-like (red/yellow/green dots, filename, copy/download buttons).

Accordions: Chevron toggle, header badges (e.g., "12 issues").

6. Multi-Tenant UX Flows
Tenant Switcher: Dropdown in header – shows current tenant/space, quick-switch.

Scoped Breadcrumbs: "Tenants > Acme Corp > Spaces > Operations > Events".

Isolation Indicators: Subtle banner "Viewing: Acme Corp / Ops Space".

RBAC Feedback: Permission errors as toasts/modals with "Request Access" CTA.

7. Responsiveness & Accessibility
Breakpoints: Desktop (>1024px): Multi-column; Tablet (768px): 1-2 col; Mobile: Stacked, hamburger menu.

Accessibility: ARIA labels, keyboard nav, high contrast, screen-reader friendly tables.

Performance: Lazy-load sections, virtualized tables (for 10k+ events), skeleton loaders.
