Quick actions (run in terminal)

  • brandos system status — full status
  • brandos system ports — list ports
  • brandos system docker restart CONTAINER — restart container
  • brandos system kill-port PORT — free port
  • brandos system health — health checks

See docs/SYSTEM_CONTROL.md in the repo for full docs.
