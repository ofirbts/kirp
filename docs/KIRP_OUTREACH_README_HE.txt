KIRP — חבילה טכנית לשליחה החוצה
================================

מה יש ב-ZIP
-----------
1) KIRP_EXECUTIVE_TECHNICAL_BRIEF.md
   המסמך לשליחה ראשונה: ~3 עמודים. VC, מייסד עסוק, רקרוטר טכני.

2) KIRP_EXECUTIVE_TECHNICAL_BRIEF_PRINT.html
   אותו תוכן בערך, עם עיצוב כהה להדפסה/PDF.
   פתח בכרום/אדג' → המתן לרינדור דיאגרמה → Ctrl+P → "שמירה כ-PDF".
   (דורש אינטרנט לפונטים ול-Mermaid מה-CDN; אם אין רשת — שלח את ה-.md במקום.)

3) KIRP_INTELLIGENCE_OS_WHITEPAPER.md
   התזה המלאה. שולחים רק למי שביקש עומק / אחרי שיחה ראשונה.

מה לשלוח בפועל
---------------
שלב א (ברירת מחדל):
  • שלח את ה-Brief: או הקובץ .md, או PDF שייצאת מה-HTML.
  • בשורת מייל אחת אפשר לציין: "מצורף Brief טכני; Whitepaper מלא זמין לבקשה."

שלב ב (רק אם מתעניינים):
  • שלח את קובץ ה-Whitepaper (.md) או העתק ל-Notion/GitHub.

לא לשלוח
---------
• לא את כל ה-repo.
• לא קוד מקור כברירת מחדל — רק אם ביקשו במפורש.

גרסה
-----
נבנה מה-repo בנתיב docs/. אם עדכנת מסמכים — בנה מחדש את ה-ZIP (או בקש לעדכן).
