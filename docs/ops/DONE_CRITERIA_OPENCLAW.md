# Done Criteria

## Bug Fix

- issue reproduced
- fix validated
- relevant tests pass
- no unrelated behavior changes

## Feature

- meets spec
- includes needed tests
- does not break existing contracts
- short docs note when behavior changes

## Refactor

- behavior unchanged
- structure and readability improved
- tests pass
- diff is clear and focused

## Merge Gate

- lint pass
- build pass
- unit tests pass
- critical integration tests pass
- reviewer/tester signoff

## Deploy Gate

- health check pass
- version check pass
- migration plan when needed
- rollback plan defined
