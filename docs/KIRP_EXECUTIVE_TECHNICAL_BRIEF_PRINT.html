Thesis

Demos reward fluency. Production rewards invariants. Agent stacks fail quiet: plausible language, wrong facts. KIRP is an execution and governance layer: events → Kafka → governed pipeline → multiple stores → runs in Redis → optional agents → audited execution.

Why now

Agents hit systems of record. Same distributed-systems failure modes — missing idempotency on effects, giant logical boundaries, no honest partial-state story — with higher blast radius. Prompt orchestration is not systems engineering.

Operating philosophy

  • Never translate infra uncertainty into user-facing certainty.
  • Hallucinated success worse than hard crash — design surfaces accordingly.
  • Autonomous without auditability = unmanaged side effects.
  • Policy down = security / governance incident, not “skip OPA.”

Closing

Adult engineering — failures visible, boundaries enforceable, recovery runnable without re-prompting an outage away.
