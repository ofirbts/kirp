# M3 IdentityOS — Governed Module inside KIRP

M3 runs as a **tenant-scoped subsystem** within KIRP. Every M3 flow is an event flow; every state change is audited; no identity action bypasses governance.

## Architecture

- **Inbound:** M3 UI/API emit events (`m3.daily_reflection_submitted`, `m3.weekly_synthesis_requested`, etc.) → Event Registry → 9-stage pipeline.
- **Storage:** Event Store (Mongo), M3 Typed Memory (in-memory stub; optional Qdrant/Postgres later), gap snapshots for KPIs.
- **Governance:** IdentityEntropyScore, OPA M3 resource types, WhatsApp escalation when score ≥ 0.6.

## API Routes (all under `/api/v1`)

| Method | Path | Description |
|--------|------|-------------|
| POST | `/m3/reflect` | Submit daily reflection → `m3.daily_reflection_submitted` |
| POST | `/m3/synthesis` | Request weekly synthesis → `m3.weekly_synthesis_requested` |
| POST | `/m3/evolution` | Request monthly evolution → `m3.monthly_evolution_requested` |
| GET | `/m3/reflections` | List reflection entries (tenant/user scoped) |
| GET | `/m3/synthesis` | List weekly syntheses |
| GET | `/m3/evolution` | List monthly evolutions |
| GET | `/m3/actions` | List micro_actions (optional `?status=pending\|completed\|snoozed`) |
| GET | `/m3/kpis` | KPIs: Daily Reflection Completion, Recall Retention, Identity Alignment, Gap Closure (`?days=7`) |
| GET | `/m3/health` | Module status (event types, agents registered) |

## Environment

See `.env.example` M3 section:

- `M3_ESCALATION_PHONE` — WhatsApp number for human approval when identity_entropy_score ≥ 0.6.
- `M3_ESCALATION_PHONE_<tenant>_<user>` — Per-tenant/user override.

## Event Types (metadata.module = "m3")

- `m3.identity_intent_declared`
- `m3.daily_reflection_submitted`
- `m3.micro_action_generated` / `m3.micro_action_completed` / `m3.micro_action_snoozed`
- `m3.weekly_synthesis_requested` / `m3.weekly_synthesis_generated`
- `m3.monthly_evolution_requested` / `m3.monthly_evolution_updated`
- `m3.identity_vector_updated`
- `m3.gap_analysis_computed`
- `m3.human_governance_required`

## Pipeline Flow

1. Intent Declared → 2. Context Retrieval (M3 memory) → 3. Pattern Analysis → 4. Plan Generation → 5. Plan Critique (Discriminator) → 6. OPA → 7. Human Governance (WhatsApp if needed) → 8. Execution → 9. Reflection & Memory Writeback.
